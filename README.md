# CityLife Insurance Dashboard Project

## Overview

This repository contains a comprehensive business intelligence solution for CityLife Insurance, featuring multiple Power BI dashboards and data analysis components designed to provide insights into sales performance, data validation, and operational metrics.

## Project Components

### Power BI Dashboards

1. **Business Ask - CityLife Insurance Dashboard - Build Visuals.pbix**
   - Primary visualization dashboard
   - Contains custom visuals and charts for business insights
   - Focuses on building comprehensive visual representations of insurance data

2. **Business Ask - CityLife Insurance Dashboard - Validate data.pbix**
   - Data validation and quality assurance dashboard
   - Ensures data integrity and identifies potential issues
   - Critical for maintaining accurate reporting

3. **Business Ask - Solution - Develop a Sales Dashboard for CityLife Insurance.pbix**
   - Dedicated sales performance dashboard
   - Tracks key sales metrics and KPIs
   - Provides actionable insights for sales teams

4. **CityLife 360 - breakdown charts.pbix**
   - Detailed breakdown analysis dashboard
   - Comprehensive 360-degree view of business operations
   - Advanced charting and analytical components

### Data Sources

- **CityLife data.xlsx** - Primary data source containing insurance business data

## Getting Started

### Prerequisites
- Microsoft Power BI Desktop
- Access to CityLife Insurance data sources
- Appropriate permissions for data connections

### Setup Instructions

1. **Open Power BI Files**
   - Launch Power BI Desktop
   - Open the desired .pbix file from the project directory

2. **Data Connection**
   - Ensure the CityLife data.xlsx file is accessible
   - Update data source connections if paths have changed
   - Refresh data connections as needed

3. **Dashboard Navigation**
   - Each dashboard serves a specific business purpose
   - Start with the validation dashboard to ensure data quality
   - Proceed to visual and sales dashboards for analysis
